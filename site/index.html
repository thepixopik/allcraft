03 / Principles

Shared by every craft

Built the hard way.

Every Crafting App is written from scratch in Rust and held to the same rules.

  1. 01

    Open source

    Every line is on GitHub under permissive MIT / Apache-2.0 licenses. Read it, fork it, build on it.

  2. 02

    Native, not wrapped

    Pure Rust compiled to WebGPU + WebAssembly and native desktop binaries. Zero Electron bloat.

  3. 03

    Familiar from day one

    Layouts, tools and shortcuts that working professionals already know, so there is nothing to relearn.

  4. 04

    Your files, your machine

    Everything runs 100% locally on your own device. Zero cloud uploads or servers between you and your work.

  5. 05

    Agent-ready

    Drive every app from a CLI, a JSON control channel or an MCP server, built for automation and AI agents.

  6. 06

    Also in your browser

    PhotoCraft, VectorCraft, FilmCraft, LightCraft, PdfCraft, EffectCraft, AniCraft, DesignCraft, TextureCraft, MaterialCraft, SoundCraft, WordCraft, DeckCraft, CADCraft and GridCraft run right in a browser tab.
